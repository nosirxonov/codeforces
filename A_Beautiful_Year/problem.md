# A. Beautiful Year

- **Manba:** https://codeforces.com/problemset/problem/271/A
- **Vaqt cheklovi:** time limit per test 2 seconds
- **Xotira cheklovi:** memory limit per test 256 megabytes

## O'zbekcha tarjima

### Masala sharti
Kechagina 2013-yil kirib kelganga o'xshaydi. Siz qiziq faktni bilasizmi? 2013 yil eski 1987 yildan keyingi birinchi yil bo'lib, faqat aniq raqamlarga ega. Endi sizga quyidagi masalani hal qilish taklif etiladi: yil raqami berilgan bo'lsa, berilganidan qat'iy kattaroq va faqat aniq raqamlarga ega bo'lgan minimal yil raqamini toping.

### Kirish ma'lumotlari (Input)
Yagona qatorda butun y (1000 ≤ y ≤ 9000) - yil raqami mavjud.

### Chiqish ma'lumotlari (Output)
Bitta butun sonni chop eting - y dan qat'iy katta bo'lgan minimal yil raqami va uning barcha raqamlari alohida. Javob mavjudligi kafolatlangan.

## Namunaviy testlar (Sample Tests)

**Input:**
