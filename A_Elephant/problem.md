# A. Elephant

- **Manba:** https://codeforces.com/problemset/problem/617/A
- **Vaqt cheklovi:** time limit per test 1 second
- **Xotira cheklovi:** memory limit per test 256 megabytes

## O'zbekcha tarjima

### Masala sharti
Bir fil do'stini ziyorat qilishga qaror qildi. Ma’lum bo‘lishicha, filning uyi 0 nuqtada, do‘stining uyi esa koordinata chizig‘ining x (x > 0) nuqtasida joylashgan. Bir qadamda fil 1, 2, 3, 4 yoki 5 pozitsiyani oldinga siljitishi mumkin. Do'stining uyiga borish uchun u qancha qadam tashlashi kerakligini aniqlang.

### Kirish ma'lumotlari (Input)
Kirishning birinchi qatori butun sonni o'z ichiga oladi x ( 1 ≤ x ≤ 1 000 000 ) — Do'stingizning uyi koordinatasi.

### Chiqish ma'lumotlari (Output)
Fil 0 nuqtadan x nuqtaga o'tish uchun bajarishi kerak bo'lgan minimal qadamlar sonini chop eting.

### Izoh (Note)
Birinchi misolda fil x nuqtasiga erishish uchun 5 uzunlikdagi bir qadamni bajarishi kerak. Ikkinchi misolda fil 3, 5 va 4 ga harakat qilsa, x nuqtasiga etib borishi mumkin. Optimal javobni olishning boshqa usullari ham bor, lekin fil uchta harakatdan kamroq vaqt ichida x ga yeta olmaydi.
