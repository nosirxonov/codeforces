# A. Domino piling

- **Manba:** https://codeforces.com/problemset/problem/50/A
- **Vaqt cheklovi:** time limit per test 2 seconds
- **Xotira cheklovi:** memory limit per test 256 megabytes

## O'zbekcha tarjima

### Masala sharti
Sizga M × N kvadratlardan iborat to'rtburchaklar taxtasi beriladi. Shuningdek, sizga cheksiz miqdordagi 2 × 1 kvadratdan iborat standart domino buyumlari beriladi. Bo'laklarni aylantirishga ruxsat beriladi. Quyidagi shartlarni bajarish uchun taxtaga iloji boricha ko'proq domino qo'yish so'raladi: 1. Har bir domino ikkita kvadratni to'liq qamrab oladi. 2. Ikkita domino bir-birining ustiga tushmaydi. 3. Har bir domino butunlay taxta ichida yotadi. Kengashning chekkalariga teginishga ruxsat beriladi. Ushbu cheklovlar ostida joylashtirilishi mumkin bo'lgan dominolarning maksimal sonini toping.

### Kirish ma'lumotlari (Input)
Bitta qatorda sizga ikkita tamsayı M va N berilgan - taxta o'lchamlari kvadratlarda ( 1 ≤ M ≤ N ≤ 16 ).

### Chiqish ma'lumotlari (Output)
Chiqish bitta raqam - joylashtirilishi mumkin bo'lgan dominolarning maksimal soni.
