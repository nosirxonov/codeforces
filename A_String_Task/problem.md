# A. String Task

- **Manba:** https://codeforces.com/problemset/problem/118/A
- **Vaqt cheklovi:** time limit per test 2 seconds
- **Xotira cheklovi:** memory limit per test 256 megabytes

## O'zbekcha tarjima

### Masala sharti
Petya dasturlash darslariga qatnasha boshladi. Birinchi darsda uning vazifasi oddiy dastur yozish edi. Dastur quyidagilarni bajarishi kerak edi: berilgan qatorda katta va kichik lotin harflaridan iborat bo'lsa, u: unlilar "A", "O", "Y", "E", "U", "I" harflari, qolganlari esa undosh tovushlardir. Dasturning kiritilishi aynan bitta satr bo'lib, u chiqishni bitta satr sifatida qaytarishi kerak, natijada dastur dastlabki qatorni qayta ishlagandan so'ng. Petyaga bu oson vazifani engishga yordam bering.

### Kirish ma'lumotlari (Input)
Birinchi qator Petya dasturining kirish qatorini ifodalaydi. Bu qator faqat katta va kichik lotin harflaridan iborat bo'lib, uning uzunligi 1 dan 100 gacha, shu jumladan.

### Chiqish ma'lumotlari (Output)
Olingan qatorni chop eting. Bu satr bo'sh emasligi kafolatlangan.

## Namunaviy testlar (Sample Tests)

### Test 1
**Input:**
```text
tour
```
**Output:**
```text
.t.r
```

### Test 2
**Input:**
```text
Codeforces
```

```text
.c.d.f.r.c.s
```

### Test 3
**Input:**
```text
aBAcAba
```
**Output:**
